# Sweelincklaan - grondpolitiek

Informatieve website voor de casus Sweelincklaan in Tilburg.

## Lokaal openen
Open index.html in een browser. Er is geen installatie of build nodig.

## Bestanden
- index.html: inhoud
- style.css: vormgeving
- app.js: interacties
- bronnen/: de PDF-bronbestanden

## Naar GitHub
Upload de inhoud van deze map naar je repository. Houd index.html en de map bronnen op hetzelfde niveau.

Voor GitHub Pages: kies bij Settings > Pages de gewenste branch en de map / (root).

Deze kopie bevat geen bestaande Git-geschiedenis of Sites-hostinginstellingen.
